# Smart Day Planner

This MVP includes:

- Daily check-in for mood, energy, stress, sleep, and notes
- Fixed-time tasks that block the day
- Flexible tasks placed in free gaps
- Feedback with actual duration, difficulty, mood after, and energy after
- Dynamic rescheduling of the remaining day after feedback

Run with:

```bash
npm start
```

Then open:

```text
http://localhost:3000
```
