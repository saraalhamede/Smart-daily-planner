Smart Day Planner

A dynamic AI-supported planner that builds realistic daily schedules from mood, energy, sleep, stress, deadlines, fixed commitments, and feedback.

React Frontend Node / Express API MySQL Database Future Python AI
Sara Alhamede & Amina Fraheen Smart Planner / Yom Chakam Personalized scheduling for student productivity

!Problem

Static planners treat every day the same, but students' real days are not static. Mood, sleep, stress, fixed classes, and low energy change what is realistic.

  • Tasks overlap with fixed commitments
  • Hard tasks are placed at low-energy times
  • Feedback is usually not used to improve the plan

✓Solution

The system generates a personalized daily schedule using user input, AI helper logic, fixed-time rules, database history, and dynamic feedback.

□System Architecture

UI
Presentation Layer React frontend: check-in, task form, schedule display, feedback panel.
API
Application Layer Node/Express server: controllers, services, validation, API responses.
AI
Processing Layer Mood analyzer, task categorizer, scheduler, feedback learning logic.
DB
Data Layer MySQL stores users, tasks, daily logs, schedules, feedback, and predictions.

AIAI Roles

Mood & Energy Analyzer Reads check-in text, sleep, stress, and energy to estimate the student's current state.
Task Categorizer Classifies tasks such as study, coding, writing, routine, or fixed commitment.
Smart Scheduler Combines fixed tasks, flexible tasks, deadlines, priority, difficulty, and energy.
Feedback Learning Uses actual duration, completion, energy after, and mood after to improve future planning.

↻Dynamic Feedback

If task is unfinished

Remaining duration is saved and rescheduled in the next free gap.

If energy becomes low

Easy tasks move earlier and hard tasks become shorter focus blocks.

DSDatasets

External datasets support initial emotion analysis, task categorization, and time estimation. The collected survey dataset helps study the connection between sleep, stress, energy, productivity, and task completion.
