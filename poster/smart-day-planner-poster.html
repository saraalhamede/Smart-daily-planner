Smart Day Planner

A dynamic AI-supported planner that organizes daily tasks according to mood, energy, sleep, stress, deadlines, fixed-time commitments, and user feedback.

Sara Alhamede Amina Fraheen Smart Planner / יום חכם React + Express + MySQL

Problem

Students often manage tasks using static to-do lists that ignore real mental state. Deadlines, stress, poor sleep, and low energy can lead to procrastination and weak productivity.

  • Too many tasks and deadlines
  • Low energy during important work
  • Stress and mood changes during the day
  • Fixed commitments that must not overlap

Solution

Smart Day Planner creates a personalized daily schedule by combining user input, rule-based AI helpers, fixed-time blocks, and feedback-based rescheduling.

  • Hard tasks are matched with higher energy
  • Easy tasks are moved earlier when energy is low
  • Fixed-time tasks reserve their exact time
  • Feedback updates the remaining day

Main Idea

The user remains the main data source. External datasets improve the initial AI logic, while personal history becomes more important as the system collects real feedback.

System Flow

User Input Mood, energy, sleep, stress, tasks, deadlines
AI Analysis Emotion, task category, duration, predicted energy
Scheduler Fixed tasks first, flexible tasks in free gaps
Daily Plan Personalized schedule with explanations
Feedback Completion, actual time, mood after, energy after

Architecture

Presentation Layer React frontend: check-in, task form, schedule view, feedback form
Application Layer Node/Express API: routes, services, validation, response handling
Processing Layer Scheduler, mood and energy analyzer, task categorizer, feedback learning
Data Layer MySQL database: users, tasks, logs, schedules, feedback, survey responses

Database

users user_preferences daily_logs tasks schedules schedule_items feedback ai_predictions survey_responses

AI Roles

Mood & Energy Analyzer Uses mood, stress, sleep, tiredness, and text notes to estimate the user's current state.
Task Categorizer Classifies tasks such as study, coding, writing, and routine work.
Smart Scheduler Combines fixed-time tasks, flexible tasks, deadlines, priority, difficulty, and energy.
Feedback Learning Uses actual duration, difficulty after, energy after, and mood after to improve planning.

Dynamic Feedback

After each task, the user reports what happened. If energy drops or a task is not completed, the remaining schedule is regenerated.

  • Completed task closes automatically
  • Unfinished task keeps remaining time
  • Low energy moves easier tasks earlier
  • Hard tasks become shorter focus blocks

Datasets

External datasets are used to improve emotion analysis, task categorization, and time estimation. Our collected survey dataset supports the relationship between sleep, stress, energy, productivity, and task completion.
