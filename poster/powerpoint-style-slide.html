Smart Day Planner

Dynamic planning using user state, AI helpers, database history, and feedback.

Sara Alhamede & Amina Fraheen B.Sc Final Project | React + Express + MySQL

?Problem

Static to-do lists ignore mood, energy, sleep, stress, and fixed commitments. The result is a schedule that may look organized but is not realistic.

OKSolution

Smart Day Planner creates a personalized schedule and changes it dynamically after user feedback.
