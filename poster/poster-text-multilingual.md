# Smart Day Planner Poster Text

## English Version

### Title
Smart Day Planner

### Subtitle
A dynamic AI-supported planner that organizes daily tasks according to mood, energy, sleep, stress, deadlines, fixed-time commitments, and user feedback.

### Problem
Students often manage tasks using static to-do lists that ignore their real mental state. Stress, poor sleep, low energy, and many deadlines can lead to procrastination and weak productivity.

### Solution
Smart Day Planner creates a personalized daily schedule by combining user input, task data, fixed-time commitments, AI helper logic, and feedback-based rescheduling.

### Main Flow
User Input -> AI Analysis -> Smart Scheduler -> Daily Schedule -> User Feedback -> Improved Scheduling

### AI Roles
Mood and Energy Analyzer, Task Categorizer, Time Estimator, Smart Scheduler, Feedback Learning.

### Database
Users, User Preferences, Daily Logs, Tasks, Schedules, Schedule Items, Feedback, AI Predictions, Survey Responses.

### Future Work
Python AI service, Arabic/Hebrew translation, real ML models, multi-user personalization, contrastive learning.

## Arabic Version

المخطط الذكي اليومي

### المشكلة
يعتمد كثير من الطلاب على قوائم مهام ثابتة لا تأخذ بعين الاعتبار حالتهم النفسية أو مستوى طاقتهم خلال اليوم. لذلك قد يؤدي الضغط، قلة النوم، كثرة المواعيد النهائية، وانخفاض الطاقة إلى التأجيل وضعف الإنتاجية.

### الحل
يقوم النظام بإنشاء جدول يومي مخصص للمستخدم من خلال دمج مدخلات المستخدم، بيانات المهام، الأوقات الثابتة، منطق ذكاء اصطناعي مساعد، والتغذية الراجعة بعد تنفيذ المهام.

### سير العمل
مدخلات المستخدم -> تحليل ذكي -> جدولة ذكية -> جدول يومي -> تغذية راجعة -> تحسين الجدولة القادمة

### أدوار الذكاء الاصطناعي
تحليل المزاج والطاقة، تصنيف المهام، تقدير الوقت، الجدولة الذكية، والتعلم من التغذية الراجعة.

### قاعدة البيانات
المستخدمون، تفضيلات المستخدم، السجلات اليومية، المهام، الجداول، عناصر الجدول، التغذية الراجعة، تنبؤات الذكاء الاصطناعي، وبيانات الاستبيان.

### التطوير المستقبلي
خدمة ذكاء اصطناعي بلغة Python، دعم الترجمة للعربية والعبرية، نماذج تعلم آلي حقيقية، تخصيص متعدد المستخدمين، والتعلم التبايني لمقارنة أنماط المستخدمين المتشابهة.
