# Poster Package

This folder contains poster materials for the Smart Day Planner final project.

## Files

- `smart-day-planner-poster.html`: full academic poster, ready to print or export as PDF from the browser.
- `final-college-poster.html`: recommended final-project version with stronger styling, illustrations, app mockup, workflow visuals, database graphic, and AI sections.
- `powerpoint-style-slide.html`: 16:9 slide-style poster layout that can be used as a presentation slide reference.
- `poster-text-multilingual.md`: poster text in English, Arabic, and Hebrew.
- `visual-poster.svg`: visual poster image in SVG format with accurate editable text.
- `technical-poster-50x70.html`: professional technical poster in Hebrew, built for 50x70 cm portrait printing.
- `presenter-notes-he.md`: short Hebrew speaking notes for explaining the poster near the demo booth.

## How to use

Open the HTML files in a browser. For PDF export, use the browser print dialog and choose "Save as PDF".

Recommended print setup:

- Best final poster: `final-college-poster.html`
- Best technical college-conference poster: `technical-poster-50x70.html`
- Full poster: A3 portrait
- Conference requirement: 50x70 cm portrait
- Slide layout: landscape or screenshot into PowerPoint

The SVG file can be opened in a browser, inserted into documents, or edited in design tools such as Figma, Illustrator, or Inkscape.
